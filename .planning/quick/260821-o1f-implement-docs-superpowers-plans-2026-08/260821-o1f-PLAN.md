# Executable Quick-Task Plan: Interactive Editorial Reconstruction

**Quick task:** `260821-o1f`
**Source plan:** `docs/superpowers/plans/2026-08-21-interactive-editorial-reconstruction.md`
**Execution mode:** dependency-ordered implementation with one atomic commit per completed slice
**Planner constraint:** this planning pass does not edit application source files

## Objective

Recompose `/` and `/about` into an interactive editorial diagnostic instrument for Nét Nút Studio while preserving the existing public routes and anchors. The finished experience must be browser-only, truthful about what it does, progressively enhanced, keyboard-usable, reduced-motion safe, and usable at 390px without horizontal overflow.

The implementation must use the existing Next.js 16.3, React 19, GSAP, Lenis, Tailwind CSS v4, and `next/font` stack. Before changing framework or navigation behavior, consult the relevant installed Next.js guidance under `node_modules/next/dist/docs/` when available and verify the current package/source APIs; do not apply pre-16 assumptions. Do not install, upgrade, or replace packages. Do not add a backend, public API, persistence, analytics, AI audit, lead submission, canvas, WebGL, stock image, or project asset.

## Decision traceability

The supplied `CONTEXT.md` does not assign numeric IDs, so this plan assigns stable IDs for execution traceability.

- **D-01 — Scope and compatibility:** follow the source plan, preserve `/`, `/about`, and `#services`, `#work`, `#capabilities`, `#process`, `#insights`, `#contact`; desktop is the art-direction target and mobile must not regress.

- **D-04 — Visual system:** active documentation and implementation use only `#090909`, `#EDEDED`, `#FF3300`, and tonal alpha variations; vermilion is reserved for intervention, active state, and conversion.
- **D-05 — Verification:** run focused checks, plan-level lint/build/diff validation, bounded browser QA, accessibility checks, reduced-motion checks, mobile checks, and post-execution verification; do not add a test dependency.
- **D-06 — Architecture:** use pure browser-side modules, a homepage-only provider, one shared reconstruction phase state, GSAP/Lenis progressive enhancement, semantic HTML before choreography, and no raw scroll listener.
